# V4 H3 incremental delivery: existing API and Web (dated, read-only)

**Scope:** attach the real, production-proven H1 GitHub manifest to existing FastAPI v1 and existing dsa-web navigation, without a parallel app, new model service, browser automation, new rating engine, broker linkage or formal trading permissions. This is H3 **code integration**, not full H3 deployment or market-opening readiness.

## Behavior and source boundaries

- API route: `GET /api/v1/investor-v4/latest` through existing FastAPI router/auth middleware; responds `Cache-Control: no-store, max-age=0`. Unlike legacy portfolio transaction APIs, this route only reads bounded H1 provenance; it cannot change positions, execute orders or invoke ChatGPT.
- Existing Web route: `/investor-v4`, available from the current sidebar as **投资研报 / Investor report**. It loads on opening, offers explicit refresh and re-requests approximately every five minutes while mounted. Every render shows the **market as-of date separately from manifest generation and page retrieval time**. Same-session opening readiness remains FALSE until a separately validated fully integrated future phase proves all actual source and brokerage checks.
- Optional configuration: `INVESTOR_V4_GITHUB_REPO=owner/name` enables a bounded six-second read of one fixed GitHub **public** Contents endpoint for the current H1 manifest, with strict owner/name validation and verified returned Git-blob bytes. No token or new GPT API. When unset or unavailable, only the locally deployed H1 copy is displayed with `LOCAL_DATED_ONLY` or `LOCAL_DATED_FALLBACK`; missing or tampered H1 is UNAVAILABLE. An HTTP 200 or today's retrieval timestamp does not confer market freshness.
- The H1 manifest is the sole input to this initial Web read path: `formal_buy_now=[]`, `formal_wait_price=[]`, every `executable_shares=0`, limited historical holdings (16) and research-only trends (5). It is **not** a current quote feed and does not promote historical recorded actions to today's orders. This intentionally limits the initial H3 surface until validated broker funds/positions/quotes, original issuer outcomes and existing Formal freshness authorization are actually wired.
- Historical per-source SHA-256 and **immutable Git blob URLs** are displayed as drill-down anchors. The mutable `main` report and pinned publication source can diverge when overlay or Three-Pillar jobs persist newer data; treat such divergence as a newer independently unvalidated source, never a silent continuity claim. The page does not fetch original filings or tell the user a proposal was approved.
- One button copies a one-time request for the user's connected GitHub-enabled ChatGPT **Web**, and a separate link opens ChatGPT. Neither opening this stock page nor data auto-refresh silently starts ChatGPT or any GPT API workflow. Existing Jev remains research-only advisory.

## Tests and acceptance

Backend: `python -m pytest -q tests/test_investor_v4_delivery.py tests/test_investor_v4_api.py`. Confirm strict published H1 contract, remote blob digest and fixed endpoint, malicious config/source rejection, missing/tampered/stale fallback, API route and no-cache headers. Frontend: `cd apps/dsa-web && npm ci && npm run lint && npm run build && npm test -- src/pages/__tests__/InvestorV4Page.test.tsx`. The dedicated `.github/workflows/investor-v4-h3-web-contract.yml` runs this actual Vitest component test on H3 PRs and main pushes; the existing global `web-gate` separately checks lint/build. Verify stale banner, distinct dates, zero tradable buys, existing holdings and pinned source links, no automatic ChatGPT calls, missing and local fallback.

**Deployment is independent of code merge.** Actual acceptance requires a reachable deployed authenticated stock Web and API, genuine H1 publisher runs on the deployed baseline, and a real screenshot from the running page; owner-specific DNS/hosting and secrets are not inferred from source code. A green test, PR merge or committed offline frontend is not production proof. H4 independent recommendation-market outcome evaluation and full H3/P1 live brokerage/issuer sources remain separate later phases.

Rollback: revert only this route, Web page/navigation/types and optional read-only downloader. H1 producer, old report, Formal authority and existing investor jobs are unchanged.
