# 硬逻辑 × 当前价格预期地图

## 目标

长期决策只回答两个问题：

1. **公司有没有硬逻辑**：判断公司/产业结构、持续盈利质量和明确公司级硬风险。
2. **当前价格能不能买**：公司硬逻辑通过后，用反向估值计算当前价格已经要求多少利润增长，再判断预期是否已经打满。

系统不再把 5000 多只股票强行压成唯一一只。多个硬逻辑公司可以同时保留，每家公司独立得到价格结论。

## 硬逻辑边界

真正可以阻断公司的包括明确公司级结构性硬风险、显式 hard-logic `FAIL/BLOCKED`、正常化持续核心利润非正。

大盘 regime、MA5/10/20/60、突破/回踩、entry、止损、Reward/Risk、仓位、execution、退出画像等在本层全部是 `non_veto_context`，不能反向否决公司质量。

普通 `RESEARCH_CANDIDATE` 也不自动等于硬逻辑确认：至少还要有可用的反向估值和不弱的持续盈利质量，否则保持 `REVIEW`。

## 反向估值

```text
required_profit_growth = current_pe / historical_reference_pe - 1

target_price = current_price
             × (1 + target_required_profit_growth)
             / (1 + current_required_profit_growth)
```

其中历史参考 PE 严格排除当前观测。

报告直接输出：

- `buyable_price_ceiling`：最高可接受买入价；
- `deep_value_price_ceiling`：深度低估价；
- 当前价格隐含利润增长；
- 有显式业务增长证据时的 low/base/high 价值价格。

没有可靠未来增长区间时不编造预测：隐含增长 <= -20% 为 `BUY_DEEP_VALUE`，<= 0 为 `BUYABLE`，> 0 则保持 `NEED_HARD_LOGIC_GROWTH_SUPPORT`。

若已有显式硬逻辑基础增长率，则按预期差分类：

- >= 30pp：`BUY_DEEP_VALUE`；
- >= 15pp：`BUYABLE_WITH_SUPPORTED_GROWTH`；
- 0–15pp：`WAIT_FOR_BETTER_PRICE`；
- < 0：`EXPECTATIONS_HIGH_WAIT`。

## 历史回归：低估买入，预期打满后退出

`hard_logic_historical_backtest.py` 使用与当前价格地图相同的反向估值逻辑做 point-in-time walk-forward 回放。

冻结规则：

- 财报只有真实披露后才可见；缺披露日时使用保守滞后，禁止把报告期日期当公开日期；
- `pd.NaT` 明确按“缺失披露日”处理，不能绕过保守披露滞后；
- 当前 PE 不进入自己的历史参考分布；
- 信号在收盘后生成，只在下一观察交易日开盘成交；
- 普通 `BUYABLE` / `BUYABLE_WITH_SUPPORTED_GROWTH` 必须同时满足 `historical_pe_percentile <= 50`；
- `BUY_DEEP_VALUE` 因预期差已经达到深度低估，可越过额外 50 分位门槛；
- 下一期开盘若高于信号日冻结的 `buyable_price_ceiling`，取消买入，不追价；
- **估值卖出必须同时满足“预期打满 + 历史 PE >= 70 分位”**；
- **硬逻辑失效不等高估值，直接退出**；
- 买卖均计 15 bps/side 摩擦成本；
- 不允许使用未来最高价、未来最低价或事后知道的牛股身份决定买卖点。

### 可重现案例捕获审计（2018-01-01 至 2026-08-18）

最新 GitHub Actions artifact 在修复 `pd.NaT` point-in-time bug 后可重现：16 只案例中 15 只有足够历史数据，14 只产生交易；长鑫科技（688825）因 2026 年 7 月才上市，没有足够自身历史行情/估值长度，保持数据不足，不伪造多年回测。

本次案例面板结果：

- 40 笔交易；
- 36 盈 / 4 亏，案例面板单笔胜率 **90.0%**；
- 单笔收益中位数 **+48.3574%**；
- 单笔收益均值 **+130.0977%**；
- 8 笔同时满足事后审计定义 `entry_price_percentile_2y <= 40`、`exit_price_percentile_2y >= 60` 且盈利的 `low_buy_high_sell`；
- 这些数字只描述事后挑选的著名股票案例面板，**不允许解释为全市场未来预期收益**。

代表性可重现交易：

- **沪电股份（002463）**：2018-04-13 约 3.4946 买入，入场历史 PE 分位约 5.83%；2024-03-12 约 29.5610 退出，单笔约 **+745.90%**，最大上行约 +775.87%，策略捕获约 96.14%。
- **中际旭创（300308）**：2023-10-27 约 63.4831 买入；2025-10-29 约 536.5680 退出，单笔约 **+745.21%**，策略捕获约 99.00%。该笔入场两年价格分位约 79.4%，说明它属于“估值预期低”而不是传统意义上的绝对股价低位。
- **长川科技（300604）**：2025-01-07 约 38.3340 买入，截至 2026-08-18 回放终点约 300.5785，标记收益约 **+684.10%**；尚未触发正式高估退出，因此是期末盯市，不是完整闭环卖出。
- **新易盛（300502）**：2024-11-01 约 65.0065 买入，截至回放终点约 451.5317，标记收益约 **+594.60%**；同样属于期末盯市。
- **紫金矿业（601899）**：2021-05-21 约 9.7087 买入，截至回放终点约 33.5097，标记收益约 **+245.15%**。
- **北方华创（002371）**：2021-12-30 约 241.5256 买入，截至回放终点约 775.8345，标记收益约 **+221.22%**。
- **宁德时代（300750）**：2019-10-15 约 36.3317 买入，2020-02-13 约 79.7517 卖出，单笔约 **+119.51%**。
- **寒武纪（688256）**：历史硬逻辑曾出现 PASS，但没有任何时点同时满足本模型的估值买入条件，因此 **NO_TRADE**。这是一项重要反证：案例后来成为明星股并不会强迫系统事后生成买点。

必须同时保留失败样本：

- 恒瑞医药一笔约 **-39.21%**；
- 洛阳钼业早期一笔约 **-13.29%**；
- 阳光电源早期一笔约 **-2.32%**，持有过程最大回撤约 **-71.97%**；
- 新易盛早期一笔因硬逻辑失效退出约 **-0.44%**。

因此当前结果支持的结论只能是：**“硬逻辑 + 反向估值”确实能在历史上捕获多只后来成为大牛股的低预期阶段，并能在部分高估阶段退出；但它不是精确抄底逃顶系统。** “估值低位”与“两年股价低位”不是同一个概念，中际旭创就是明显例子。若强行只买价格分位最低的股票，会漏掉盈利快速上升但股价已脱离绝对底部的公司。

案例面板的策略累计收益也普遍没有跑赢这些大牛股同区间 buy-and-hold；中际旭创是明显例外。原因很直接：高估退出能降低一部分预期透支，但也会让长期复利公司过早下车。因此卖点应继续以“预期打满 / 硬逻辑失效”为主，而不能为了追求图形上的最高点使用未来价格信息。

### 收益数字如何解释

这 16 只股票是**事后挑选的著名股票捕获审计**，存在严重 selection bias / survivorship bias。产物固定保存：

```text
famous_case_selection_bias_warning = true
headline_expected_return_allowed = false
```

所以 **90% 胜率、+48.36% 中位单笔收益、+130.10% 平均单笔收益都不能作为未来策略预期收益**。要估计真实期望收益，下一层必须使用历史时点全市场股票池，纳入当时上市股票、后来退市股票、IPO 时点、不可交易样本和数据失败，并与等权/指数基准比较。

## 回归输出

- `historical_signals.csv`：历史 BUY / SELL 信号及当时可见估值；
- `historical_trades.csv`：下一期开盘真实回放的逐笔收益、最大回撤、最大上行、捕获率；
- `famous_case_results.csv`：著名股票逐只捕获结果；
- `data_failures.csv`：数据不足案例；
- `historical_backtest_summary.json`；
- `historical_backtest.md`；
- `gate_diagnostics.csv/json`：逐层记录财报可见性、硬逻辑 PASS、估值买点、低估区和买价上限是否可达；若全部 `buy_ready_points=0`，诊断 workflow 直接失败。

## 生产输出与安全边界

生产链生成 `hard_logic_price_map.csv`、`hard_logic_price_map.md`、`hard_logic_price_map_summary.json`。

始终保持：

- `global_top1_required = false`；
- `technical_context_is_non_veto = true`；
- `formal_signal_eligible = false`；
- `automatic_promotion_allowed = false`；
- `no_auto_trade = true`。

原有 Formal BUY、止损、仓位、退出画像仍可作为独立执行/风险审计视图，但不能决定长期公司质量和估值地图。

本功能的仓库级变更摘要记录在 `docs/CHANGELOG.md` 的 `[Unreleased]` 部分。
